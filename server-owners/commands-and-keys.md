# Commands and Keys

## Players

| Key / command | Default | What it does |
|---|---|---|
| Open phone | **F1** / `/phone` | Opens or puts away the phone |
| Quick accept | **Y** | Answers an incoming call without opening the phone |
| Quick decline | **N** | Declines an incoming call |
| End call | **Backspace** | Ends a call after the phone was put away |
| Remove case | **J** | Takes the case off while the phone is up |
| Free the mouse | **Left Alt** | Lets the mouse leave the phone while it stays open |

Players can rebind every key in **GTA Settings > Key Bindings > FiveM**.

## Admins

| Command | What it does |
|---|---|
| `/phoneadmin` | Opens the [admin panel](in-game-panel.md) in game |
| `/phoneadminwhy` | Explains why you can or cannot open the panel |
| `phoneadminwhy <id>` (server console) | The same for any online player |

The admin command name can be changed with `Config.Admin.Command`.
