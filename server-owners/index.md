# GFX Phone for Server Owners

Everything you need to install [GFX Phone](https://gfxscripts.com/phone) on a FiveM server and run
it day to day. No coding is needed: after the files are in place, the setup is done in the admin
panel - from your browser at [phone.gfxscripts.com](https://phone.gfxscripts.com) or in game with
`/phoneadmin`.

1. Check the [requirements](requirements.md).
2. Follow the [installation](installation.md) - three steps.
3. Finish the [setup wizard](setup-wizard.md) - the phone starts the moment you press **Finish**.
